# naviiii07 — Developer Portfolio

A responsive, static portfolio website built with HTML, CSS, and JavaScript.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Sign in to GitHub as `naviiii07`.
2. Create a **public** repository named `portfolio`.
3. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root (not inside another folder).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then Save.
7. Wait for GitHub Pages to publish. Your site should appear at:
   `https://naviiii07.github.io/portfolio/`

## Personalize before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your real professional email.
- Update the LinkedIn URL to your actual profile.
- Review the project descriptions and publish only details you can verify and discuss.
- Add actual repository links and screenshots for projects when available.
- Update the skills list to reflect your current proficiency.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and current year
